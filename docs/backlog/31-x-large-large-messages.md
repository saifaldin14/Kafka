# X-LARGE: Large messages

> Crates: `alluvium-records`, `alluvium-storage`, SDK · Kafka counterpart: none (Alluvium enhancement) · Milestones: M11

Large payloads without memory pressure: chunked records for native clients, and transparent object-store offload (claim check) for Kafka clients.
